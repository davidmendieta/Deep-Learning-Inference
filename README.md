# Deep-Learning-Inference
Low-Latency Deep Learning Inference for Order-Book Return Prediction

This is a project about the optimization of the deployment of a Deep learning model (instead of being about the model itself).
Checkout project_report.pdf for all the details concerning the project.

The used data set can be found in https://www.kaggle.com/competitions/optiver-trading-at-the-close/data train.csv
